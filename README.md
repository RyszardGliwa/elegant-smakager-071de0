# AFTERDARK

AFTERDARK is a responsive DJ discovery and events portal for an independent music collective. The landing experience combines a featured radio transmission, city-filtered event listings, a resident artist roster, newsletter signup feedback, and a booking enquiry flow.

## Technology

- TanStack Start and TanStack Router
- React 19 and TypeScript
- Tailwind CSS pipeline with a custom responsive design system
- Lucide icons
- Netlify deployment adapter

## Local development

Install dependencies with `pnpm install`, then run `pnpm dev`. The production bundle is generated with `pnpm build`.

The interface currently uses curated demonstration content and client-side interaction states. Connect event, artist, mailing-list, and booking data to persistent services when real editorial workflows are introduced.
